# 环测 LIMS 业务流程 V3

命名日期：2026-09-24。

按用户指定，将当前已实施流程统一命名为 V3。V2 基线指实验室直接调度、使用原商务/技术评审岗位且保留销售排期确认的流程。

V3 包含：商务部下单、全量订单查询/导出和直接排期/改期；董事长负责商务评审；总经理负责技术评审及原有报告终审；双评审独立记录和驳回重提轮次隔离；提前改期设备刷新修复；所有订单移除销售排期确认。到样、设备、变更闭环、结果提交、报告初审/终审和财务规则继续适用。

业务版本命名不直接改写数据库内部 workflow_version 兼容枚举，不改变订单状态。
