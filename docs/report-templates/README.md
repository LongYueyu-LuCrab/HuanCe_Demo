# 环测 LIMS 报告模板

`HuanCe_Report_Template.docx` 是当前唯一报告模板。

草稿版和正式版暂时共用这一份模板。两种类型由系统的 `report_type` 控制；正式版暂不叠加电子公章，待取得公章电子版后再增加固定盖章层，不改变正文结构和动态字段。

模板中的动态字段使用 `【显示名称｜字段键】` 标记，固定内容包括公司信息、报告章节、注意事项、表头、签字角色和页脚结构。模板没有内置任何参考文件中的实验名称、样品数据、实验时长、检测结果、设备信息或样例照片。

字段、权限和后续在线编辑限制见：

- `E:/WorkSpace/template_work/artifact.md`（生成审计记录）

后续接入在线报告编辑器时：

1. 草稿与正式均从此模板加载。
2. 仅开放字段映射表中的动态字段和试验图片区域。
3. 正式版仍需经过审核流程后生成最终文件。
4. 公章作为系统固定层处理，不开放普通编辑者修改。
